# countriesmarketcap.com

The CoinMarketCap of nation-states. Countries ranked by total market cap (national net wealth), GDP, debt-to-GDP, and population.

## Stack

- Next.js 15 (App Router)
- React 19
- Tailwind CSS 3
- Deployed on Vercel

## Local dev

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Data

See [lib/countries.ts](lib/countries.ts) for the dataset and `// Methodology` block at the top of the file for sourcing notes.
